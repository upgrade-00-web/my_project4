# Лабораторная работа № 18 — вариант 11
## Обнаружение и измерение царапин на поверхности

Программа обрабатывает изображения поверхности и выделяет царапины с помощью фильтра Собеля, пороговой обработки и морфологических операций. Для найденных областей рассчитывается оценочная длина в пикселях.

**Задание варианта 11 по методическим рекомендациям:** поверхность с царапинами; обязательные операции — фильтр Собеля, порог, морфология и измерение длины царапин.

---

## 1. Что делает программа

1. Загружает изображения из папки `images`.
2. Переводит цветное изображение в оттенки серого.
3. Сглаживает мелкий шум.
4. Вычисляет градиент оператором Собеля.
5. Применяет порог и формирует чёрно-белую маску.
6. Выполняет морфологическое открытие и закрытие.
7. Находит связные области и оценивает длину каждой царапины.
8. Сохраняет промежуточные изображения, итоговые изображения и таблицу CSV.

## 4. Установка

Требуется Python версии 3.10 или выше. Откройте терминал в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

В Windows, если команда `python` не распознаётся, используйте:

```bash
py -m pip install -r requirements.txt
```

## 5. Запуск программы

**Обработка подготовленных тестовых изображений:**

```bash
python cli.py --input images --output results
```

**Создание тестовых изображений заново и запуск:**

```bash
python cli.py --input images --output results --generate-samples
```

**Обработка собственных фотографий:**

1. Поместите фотографии поверхности в папку `images`.
2. Поддерживаются форматы PNG, JPG, JPEG, BMP, TIF и TIFF.
3. Выполните команду:

```bash
python cli.py --input images --output results
```

## 6. Настройка параметров

Пример запуска с заданными параметрами:

```bash
python cli.py --input images --output results --threshold 45 --kernel-size 3 --min-area 12 --blur-size 3
```

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `--threshold` | 45 | порог бинаризации результата Собеля |
| `--kernel-size` | 3 | размер ядра морфологии; число должно быть нечётным |
| `--min-area` | 12 | минимальная площадь области, считающейся объектом |
| `--blur-size` | 3 | размер предварительного гауссова размытия; число должно быть нечётным |
| `--seed` | 42 | начальное значение генератора случайных чисел |

Слишком низкий порог может выделять шум, а слишком высокий — пропускать слабоконтрастные царапины. Размер морфологического ядра влияет на удаление мелких фрагментов и соединение близких частей.

## 7. Эксперимент

Для сравнения трёх наборов параметров выполните:

```bash
python experiment.py
```

Таблица эксперимента будет сохранена в `results/experiment/experiment.csv`. В ней указаны параметры обработки, число найденных областей, оценочные длины, MSE, PSNR и SSIM.

## 8. Результаты контрольного запуска

При запуске с параметрами по умолчанию на приложенных тестовых изображениях получены следующие значения:

| Изображение | Найдено областей | Длины, пикс. | PSNR, дБ | SSIM |
|---|---:|---|---:|---:|
| `surface_1.png` | 2 | 440,8; 324,2 | 35,86 | 0,9651 |
| `surface_2.png` | 1 | 439,7 | 35,53 | 0,9653 |
| `surface_3.png` | 1 | 439,8 | 34,36 | 0,9637 |

Эти значения относятся только к приложенным тестовым изображениям и указанным параметрам. При обработке других фотографий результаты будут отличаться. Метрики MSE, PSNR и SSIM здесь сравнивают исходное изображение с изображением, на которое нанесена разметка найденных областей; это вспомогательные показатели изменения изображения, а не абсолютная оценка точности обнаружения.

## 9. Важное замечание об измерении длины

Длина царапины рассчитывается в пикселях по протяжённости связной области вдоль её главной оси. Это оценка длины на изображении. Для перевода результата в миллиметры необходима калибровка масштаба съёмки — количество пикселей на один миллиметр.
